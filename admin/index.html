Menü Yönetim Paneli

Anahtarı nereden alırım?
  1. GitHub'da Settings → Developer settings → Personal access tokens → Fine-grained tokens sayfasına gidin.
  2. Generate new token: süre seçin, Repository access kısmında sadece bu menü deposunu seçin.
  3. Permissions → Contents iznini Read and write yapın ve oluşturun.
  4. Çıkan anahtarı buraya yapıştırın. Personel için ayrı anahtar oluşturabilir, istediğiniz zaman iptal edebilirsiniz.
